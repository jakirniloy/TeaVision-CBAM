## 📌 Overview

TeaVision-CBAM is a deep learning-based tea leaf disease detection framework designed using a **Custom Convolutional Neural Network (CNN)** integrated with the **Convolutional Block Attention Module (CBAM)**.  

The model focuses on improving feature extraction by applying both **channel attention** and **spatial attention**, enabling precise identification of tea leaf diseases from image data.

This project aims to support:
- Smart agriculture
- Precision farming
- Automated plant disease diagnosis
- AI-driven crop monitoring systems

## 🏗️ Model Architecture

The proposed framework consists of:

1. Input Image Processing
2. Convolutional Layers
3. CBAM Attention Module
4. Feature Extraction
5. Dense Classification Layers
6. Softmax Output Layer

### 🔍 CBAM Components
- Channel Attention Module
- Spatial Attention Module

The integration of CBAM enhances the model's capability to focus on disease-affected regions of tea leaves.
